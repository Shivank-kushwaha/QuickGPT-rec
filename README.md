# 🚀 QuickGPT – AI Powered Chat Application

QuickGPT is a modern AI-powered chatbot application built using the MERN stack. It provides users with a fast, responsive, and interactive chat experience similar to ChatGPT. The project focuses on clean UI, real-time AI responses, authentication, and smooth user interaction.

🔗 **Live Demo:** https://quick-gpt-frontend-psi.vercel.app/  
💻 **GitHub Repository:** https://github.com/Shivank-kushwaha/QuickGPT-rec

---

# ✨ Features

- 🤖 AI Chat Interface
- 🔐 User Authentication & Authorization

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Shivank-kushwaha/QuickGPT-rec.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd QuickGPT-rec
```

---

# 🚀 Frontend Setup

```bash
cd client
npm install
npm run dev
```

Frontend will run on:

```bash
http://localhost:5173
```

---

# 🚀 Backend Setup

```bash
cd server
npm install
npm run server
```

Backend will run on:

```bash
http://localhost:5000
```

---

# 🔑 Environment Variables

Create a `.env` file inside the server folder and add:

```env
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
OPENAI_API_KEY=your_api_key
```

---

# 🧠 How QuickGPT Works

1. User sends a message
2. Frontend sends request to backend API
3. Backend processes the request
4. AI model generates response
5. Response is displayed instantly in chat UI
